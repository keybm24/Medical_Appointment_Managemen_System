# Medical Appointment Management System

Desktop application developed in Java for the comprehensive management of medical appointments. Allows healthcare staff to schedule, consult, modify, and cancel appointments through an intuitive interface, integrated with a MySQL relational database for persistent and structured data storage.

## Features

- Schedule new medical appointments
- Query existing appointments
- Modify appointment details
- Cancel appointments
- Persistent data storage with MySQL relational database
- Patient and doctor management

## Technologies

- Java
- MySQL — Relational database
- JDBC — Database connectivity

## How to Run

1. Clone the repository:
```bash
   git clone https://github.com/keybm24/Medical_Appointment_Managemen_System-.git
```
2. Import the project into your preferred IDE (NetBeans / IntelliJ / Eclipse)

3. Set up the MySQL database:
   - Create a database named `citas_medicas`
   - Import the SQL script included in the `/database` folder

4. Configure the database connection in the project:
   - Update the credentials in the connection file with your MySQL username and password
